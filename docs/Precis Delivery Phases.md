# Precis Delivery Phases

## Phase 1: Foundation and core UX
- Xcode app project and base app shell
- data model and persistence layer
- feed input and validation flow
- article list and reading pane shell

## Phase 2: Feed pipeline and reading features
- feed refresh pipeline and diffing
- OPML import/export and folder organization
- read state, star, and later-queue handling
- local search baseline and smart folder basics

## Phase 3: AI summarization
- provider abstraction and Apple Intelligence integration
- local summary generation with fallback logic
- summary storage and UI treatment as marginal annotation

## Phase 4: Sync, background work, and polish
- CloudKit sync layer
- background refresh scheduler and unread badge logic
- app intents and system integration
- accessibility and keyboard polish

## Phase 5: QA and beta prep
- release validation
- sandbox review
- visual QA against the design baseline
- beta testing and final release notes
