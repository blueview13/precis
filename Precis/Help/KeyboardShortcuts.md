# Keyboard Shortcuts

| Keys | Action |
| --- | --- |
| **Space** | Open the next article |
| **↑ / ↓** | Move through headlines |
| **d** | Mark the selected article read or unread |
| **s** | Star or unstar the selected article |
| **⌘,** | Open Settings |
| **⌘?** | Open Help |

Space works in the window except while typing in a text field or when the article page has focus. Arrow keys, **d**, and **s** act on the headline list; click it first if it is not focused. **Return** confirms dialogs and inline edits; **Esc** cancels them.
