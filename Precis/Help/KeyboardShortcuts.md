# Keyboard Shortcuts

| Keys | Action |
| --- | --- |
| **Space** | Next article |
| **↑ / ↓** | Previous / next article |
| **d** | Mark the selected article read or unread |
| **s** | Star or unstar the selected article |
| **⌘,** | Open Settings |
| **⌘?** | Open this Help window |

Space works anywhere in the window except while you're typing in a text field or when the article page itself has focus. The arrow keys, **d** and **s** act on the headline list — click it first if it isn't focused.

Return confirms dialogs and inline edits; Esc cancels them.
